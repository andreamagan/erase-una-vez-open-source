# Illustrations

Andrea Magán Rey's hand-drawn artwork, without text, so it can be reused
in translations, talks and new layouts.

- `scenes/` — the book illustrations, named after the page they're on
  (`page-12.webp` → page 12). Double-page spreads are split in two.
- `characters/` — character sheets.
- `share/` — ready-to-share images, text included, one per language
  (`do-pobo-ao-proxecto.gl.jpg`: the story ↔ open source map).

These are web-sized copies (max. 1600 px). Print-resolution originals
will be shared as GitHub Release assets.
