# Érase unha vez un proxecto Open Source

*("Once upon a time, an open source project")* — a story for learning
about licenses, communities and contributions, told with a cardboard
box, a cat named **Teky**, and the animals of a forest.

Written and illustrated by Andrea Magán Rey. It was born as a talk for
WordCamp Galicia 2026 and grew into an illustrated book. This
repository is the project in the open: the book text, the talk script,
the illustrations and the website.

## Status

- **The book**: preview edition (v0.1) in Galician, 36 pages. A small
  test print exists — not for sale, no ISBN — to share at the talk and
  gather feedback before a first proper edition. You can
  [flip through it online](https://eraseunavezopensource.org/conto/).
  A Spanish translation is open to contributors.
- **The talk**: WordCamp Galicia, 16–18 October 2026, A Coruña. Given
  in Galician, 10 minutes.

## Language

The story is written in Galician (master text). Everything *around* the
story — this README, `CONTRIBUTING.md`, issue labels — is in English, so
anyone can find and use the project wherever they're from.

## License

Two licenses for two different things — see
[CONTRIBUTING.md](CONTRIBUTING.md#first-two-licenses) for the detail:

- **Content** (story, script, characters, illustrations): [CC BY-NC
  4.0](LICENSE). Free to share, translate and adapt for non-commercial
  use, with attribution; commercial use needs permission.
- **Code** (website and scripts): [MIT](LICENSE-CODE).

**Open in spirit, not "open source" by the book.** Strictly speaking,
the Open Source Definition doesn't allow restricting commercial use, so
a CC BY-NC work isn't open source. That's deliberate: anyone can read,
tell, translate and adapt this story for free, but commercial print
runs go through the author. The preview print calls the book "open
source": that's on the errata list for the next version.

The licenses explained *inside* the story (MIT, GPL, Apache) are part
of the narrative, not the license of this work.
