# Do pobo ao proxecto

<!-- p. 30–31 -->

O que empezara como unha caixa de ideas de Teky, co tempo, foise
convertendo nun proxecto aberto. Aquí podes ver como se parecen.

| No conto          | No proxecto                                                             |
| ----------------- | ----------------------------------------------------------------------- |
| Teky              | A persoa creadora                                                       |
| A caixa           | O proxecto                                                              |
| Os planos         | O código fonte                                                          |
| Licencio          | Avogado ou asesor                                                       |
| A Nota            | Licenza do proxecto — LICENSE.md                                        |
| O taboleiro       | Plataforma de publicación (GitLab, GitHub...)                           |
| As instrucións    | README.md                                                               |
| Tui               | Difusión do proxecto. Redes, boca a orella, eventos...                  |
| As contribucións  | Issues, PRs, bugs, tests, deseño, docs, reviews, traducións...          |
| Todo o pobo       | Comunidade madura, gobernanza compartida                                |
| Os carteis        | Normas de uso e comportamento — CONTRIBUTING.md e o CODE_OF_CONDUCT.md. |
| Gardián e o buzón | Reportar vulnerabilidades. — SECURITY.md                                |
| Os mapaches       | Un fork do proxecto                                                     |
