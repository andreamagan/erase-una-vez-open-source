# The book

One folder per language. `gl/` is the master: the text exactly as it
appears in the preview edition (v0.1, test print, 2026), typos
included — fixes go through issues so the next version picks them up.

| File | What it is | Pages |
|---|---|---|
| `texto.md` | The story | 6–29, 32 |
| `creditos.md` | Credits and license | 4 |
| `dedicatoria.md` | Dedication | 5 |
| `do-pobo-ao-proxecto.md` | Summary: story ↔ open source project | 30–31 |
| `agradecementos.md` | Acknowledgements | 33 |
| `contraportada.md` | Back cover | 36 |

The `<!-- p. N -->` comments mark where each fragment sits in the
layout. Keep them when translating.

## Translating

Copy `gl/` to a folder named after the language code (`es/`, `en/`…),
keep the same file names and paragraph structure, and translate. The
file names stay in Galician on purpose: every language uses the same
ones, so the website and tools can find them.
