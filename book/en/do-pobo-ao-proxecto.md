# From the town to the project

<!-- p. 30–31 -->

What began as a box of ideas from Teky gradually evolved
into an open project. Here you can see how they resemble each other.

| In the story            | In the project                                                          |
| ----------------------- | ----------------------------------------------------------------------- |
| Teky                    | The creator                                                             |
| The box                 | The project                                                             |
| The blueprints          | The source code                                                         |
| Licencius               | Lawyer or advisor                                                       |
| The note                | Project license — LICENSE.md                                            |
| The board               | Publishing platform (GitLab, GitHub...)                                 |
| The instructions        | README.md                                                               |
| Tui                     | Dissemination of the project. Social networks, word of mouth, events... |
| The contributions       | Issues, PRs, bugs, tests, design, docs, reviews, translations...        |
| The whole town          | Mature community, shared governance                                     |
| The posters             | Rules of Use and Conduct — CONTRIBUTING.md and the CODE_OF_CONDUCT.md.  |
| Gardian and the mailbox | Report vulnerabilities. — SECURITY.md                                   |
| The raccoons            | A fork of the project                                                   |
