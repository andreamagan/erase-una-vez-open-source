# Do pobo ao proxecto

<!-- p. 30–31 -->

Lo que empezara como una caja de ideas de Teky, con el tiempo, se fue convirtiendo en un proyecto abierto. Aquí puedes ver cómo se parecen.

| En el cuento | En el proyecto |
|---|---|
| Teky | La persona creadora |
| La caja | El proyecto |
| Los planos | El código fuente |
| Licencio | Abogado o asesor. |
| La Nota | Licencia del proyecto — LICENSE.md |
| El tablero | Plataforma de publicación (Gitlab, Github..) |
| Las instrucciones | README.md |
| Tui | Difusión del proyecto. Redes, boca a boca, eventos... |
| Las contribuciones | Issues, PRs, bugs, tests, diseño, docs, reviews, traducciones... |
| Todo el pueblo | Comunidad madura, gobernanza compartida |
| Los carteles | Normas de uso y comportamiento — CONTRIBUTING.md y CODE_OF_CONDUCT.md. |
| Guardián y el buzón | Reportar vulnerabilidades — SECURITY.md |
| Los mapaches | Un fork del proyecto |
