# Security

In the story, Gardián leaves a small mailbox for urgent or delicate
warnings that shouldn't be pinned to the public board. This is it.

## What's in scope

This repository is a story, not a software library, so the surface is
small: the website in `site/`, the build script in `.github/scripts/`
and the GitHub Actions workflow.

## How to report

Please **don't open a public issue**. Use GitHub's private reporting
instead: go to the **Security** tab of this repository and click
**Report a vulnerability**.

You'll get an answer within a week. Once it's fixed, you'll be credited
in the fix if you want to be.
