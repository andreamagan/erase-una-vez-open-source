# Code of conduct

In the story, Norma hangs a few signs next to the box so everyone knows
how to behave around it. These are ours.

## The signs

- **Be kind.** Assume good intentions, and say things the way you'd
  like to hear them.
- **Every hand counts.** A typo fix is as welcome as a full
  translation. Nobody needs to know everything.
- **Disagree about the work, never about the person.**
- **Ask before touching what isn't yours.** If someone's already on an
  issue (🔵 *in progress*), talk to them first.
- **Mind the little ones.** This is a story for children, too: keep
  everything you post suitable for all ages.

Not OK, anywhere in this project: harassment, insults, discriminatory
jokes or language, unwelcome sexual content, publishing someone's
private information, or deliberately making others feel unwelcome.

## If something goes wrong

Write to **CONTACT_EMAIL**. Reports are read by the maintainer only and
kept confidential. The maintainer may remove comments, issues or PRs,
or block people who don't respect these signs.

This applies to the repository, its issues and PRs, and any space where
someone represents the project.

This code is inspired by the
[Contributor Covenant](https://www.contributor-covenant.org/).
